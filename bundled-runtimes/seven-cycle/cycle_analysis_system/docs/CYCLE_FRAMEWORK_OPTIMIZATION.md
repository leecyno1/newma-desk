# 周期叠加预测框架分析与优化报告

## 1. 现有框架分析

### 1.1 核心思想
用户提出的框架基于“周期叠加”理论，即经济/市场走势是由多个不同频率的周期波叠加而成的。具体设定了5个基准周期：
- **200个月 (~16.7年)**: 对应库兹涅茨周期（房地产/建筑周期）。
- **100个月 (~8.3年)**: 对应朱格拉周期（设备投资周期）。
- **42个月 (~3.5年)**: 对应基钦周期（库存周期）。
- **21个月 (~1.75年)**: 短期波动（可能是政策或流动性的小周期）。
- **12个月 (1年)**: 季节性周期。

### 1.2 现有代码 (Gaussian Wave Filtering) 批判
通过阅读 `【南方基金课题】周期滤波` 中的代码，发现其核心逻辑是：
1.  **FFT 变换**: 将时间序列转为频域。
2.  **高斯窗函数**: 在频域中提取特定频率（如 1/42）。
3.  **IFFT 逆变换**: 还原回时域。
4.  **预测逻辑**: 代码中的预测部分存在严重逻辑缺陷。
    - `output = np.concatenate((ret[-len(wave):], ret[:n_predict]))`
    - 这种写法本质上是利用了 FFT 的**循环卷积**性质，将序列**开头**的数据作为**未来**的预测。
    - **批判**: 经济数据不是完美的正弦波，历史不会简单重复。这种预测方法在非平稳序列（如长期增长的GDP或有结构性变化的股市）上完全失效，且存在严重的“未来函数”嫌疑（因为FFT是全局变换，边缘效应会泄露未来信息）。

### 1.3 框架评价
- **优点**: 
    - 结构清晰，符合经典经济周期理论。
    - 解耦分析有助于理解当前市场处于哪个周期的哪个阶段（共振向上还是相互抵消）。
- **缺点**:
    - **周期漂移**: 真实的经济周期长度是不固定的。例如基钦周期可能在30-50个月之间波动，固定42个月的滤波器可能漏掉变异的周期。
    - **线性叠加假设**: 假设 $Y = A + B + C + D + E$ 是线性的。实际上各周期之间存在非线性耦合（例如：长周期下行时，短周期的反弹力度会被压制）。
    - **数据处理**: 简单的环比（MoM）噪音极大，容易掩盖中长周期信号。

## 2. 优化方案：深度学习与自适应滤波

为了解决上述问题，建议采用 **"自适应分解 + 非线性预测"** 的新框架。

### 2.1 数据预处理优化
- **去噪与去趋势**: 不建议直接用原始环比。
    - 建议使用 **Log-Levels** 进行 **HP滤波 (Hodrick-Prescott Filter)** 提取循环项，或者使用 **同比 (YoY)** 序列（自带平滑和去季节性，但需注意保留12个月周期的话不能只看YoY）。
    - 如果必须保留12个月周期，建议使用 **Log-Difference (一阶差分)** 并配合 **移动平均** 平滑。

### 2.2 分解算法升级 (Decomposition)
放弃简单的固定频率高斯滤波，改用 **带通滤波器组 (Filter Bank)** 或 **VMD (变分模态分解)**。

- **方案 A (稳健型 - 推荐)**: **Butterworth 带通滤波器组**
    - 不只看单一频率，而是看一个频带。
    - 例如 42个月周期，设置通带为 [30个月, 54个月]。这样即使周期漂移，也能捕捉到能量。
    - 使用 `scipy.signal.sosfiltfilt` 实现零相位滤波（无滞后）。

- **方案 B (进阶型)**: **VMD (Variational Mode Decomposition)**
    - 设定 K=5 个模态。
    - 初始化中心频率为 [1/200, 1/100, 1/42, 1/21, 1/12]。
    - 让算法自动寻找最佳的中心频率和带宽。

### 2.3 预测模型升级 (Prediction)
放弃 FFT 循环外推，改用 **深度学习序列模型**。

- **模型架构**: **LSTM (长短期记忆网络)** 或 **TCN (时间卷积网络)**。
- **输入**: 过去 N 个月（如 60个月）的 5 个分解分量 + 原始宏观经济指标。
- **输出**: 未来 K 个月（如 12个月）的目标值。
- **逻辑**: 模型学习的是“当长周期处于下降阶段、短周期处于触底反弹阶段时，未来往往如何走”，而不是简单的正弦波延伸。

## 3. 实施路线图

1.  **数据清洗**: 统一清洗 1984-2024 数据，处理缺失值。
2.  **特征工程**: 实现 `AdaptiveCycleFilter`，将单一指标分解为 5 个频带分量。
3.  **模型构建**: 构建 `DeepCyclePredictor`，输入分解后的分量，训练 LSTM/MLP 模型。
4.  **回测验证**: 滚动回测（Rolling Walk-forward），严禁使用未来数据（滤波时需注意边缘效应，训练时只能用截止当日的数据进行滤波和训练）。
