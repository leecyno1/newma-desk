# Huatai Model Specification (Working Draft)

本文件用于整理《经济周期实证、理论及应用》（华泰）报告中的核心框架，便于后续完整复现与对比。

> 说明：本文件不会复制原文内容，而是抽象出指标体系、周期划分和策略逻辑，作为再实现的“技术规范”。

## 1. 指标体系 (待补充)

粗略分类如下，具体列表需在重新精读 PDF 后补充：

- 增长相关：工业增加值、名义/实际 GDP、发电量等
- 物价相关：CPI、PPI、CRB、大宗商品价格指数
- 金融条件：利率、信用利差、货币供应量
- 股票市场：主要宽基指数、行业指数、风格因子

## 2. 周期划分框架 (待补充)

- 长周期（~200 月）：对应结构性/总需求大周期，主要在通胀与大宗商品中体现
- 中周期（~100 月）：投资/信贷周期
- 库存周期（~42 月）：工业生产和盈利的 3–4 年周期
- 短周期（~21 月）：政策/流动性
- 季节性（~12 月）：年度因素

后续会结合我们已有的带通滤波框架，对比其参数设定。

## 3. 策略与回测设置 (待补充)

需要从 PDF 中梳理：

- 使用了哪些可投资资产（指数/行业/风格）
- 依据哪些周期信号进行仓位/行业调整
- 回测区间、再平衡频率、交易成本假设

## 4. 与当前框架的衔接

在完成本规范后，我们将：

1. 使用 Tushare 数据构建对标的月度数据库（`huatai_db_monthly.parquet`）
2. 按本规范实现高斯滤波版周期提取，与现有 Butterworth 带通框架并行
3. 在统一数据源和样本区间下，对比两套周期划分与资产表现的差异
