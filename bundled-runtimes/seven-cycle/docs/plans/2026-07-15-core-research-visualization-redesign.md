# 七周期核心研究可视化重做

## 定位

本轮重做聚焦周期研究与资产研究，不包含领导驾驶舱、审批、导出或交易执行。

## 已废弃的主 3D 语义

- 七周期时间轨迹线作为主 3D
- 跨资产分类柱体地形
- 周期贡献柱体立方体

这些表达无法直接回答“两个周期状态组合如何影响某项资产的收益或风险”。

## 新主视图

- X：选定周期的相位角（0°–360°）
- Y：第二个周期的相位角（0°–360°）
- Z：选定资产的历史观察收益与前瞻预期收益
- 黑点：历史真实观测
- 连续曲面：环形相位距离核回归的拟合结果
- 红点：当前周期状态与当前资产预期收益
- 橙色路径：周期相位与资产预期收益的未来路径

曲面只有在至少 36 期有效样本且留一法外样本表现优于历史均值时发布；否则只保留历史散点并显示 `not_identifiable`。

## 同页研究链

1. 3D 周期—资产响应面
2. C1–C7 历史相位路径、当前状态、振幅、斜率、置信度与预测区间
3. 跨资产当前到未来的风险收益迁移图

三部分使用同一发布版本和 URL 筛选状态。

本轮已完成服务端可识别性检验、只读 `/v1/surfaces/cycle-asset` API、响应面渲染和联动页面。前端只读取服务端结果，不在浏览器内重新估计。`cycle_asset_surface.parquet` 已纳入 catalog schema v2、manifest checksum、稳定 view、原子写入和批量物化入口；旧 run 缺少该产品时保留受控派生兼容，新 run 优先读取定时发布产品。
