# 投委会讨论协议

> 本文件定义投委会讨论的标准流程、输入输出格式和决策规则。
> 投委会主席（主会话）按此协议调度各Agent线程。

## 标准讨论流程（四轮制）

### 第一轮：独立观点（并行）
投委会主席向相关Agent分发同一议题，各Agent独立输出观点。

**输入**：议题 + 背景材料
**输出格式**（每个Agent必须按此格式）：
```
【席位】：XX-XX 角色名
【核心观点】：一句话结论
【置信度】：高/中/低
【关键假设】：列出2-3个核心假设
【数据支撑】：关键数据点（附来源）
```

### 第二轮：交叉质询（并行）
投委会主席将各Agent观点汇总后分发，要求每个Agent对其他人的观点提出质疑或补充。

**输入**：第一轮所有Agent的观点汇总
**输出格式**：
```
【席位】：XX-XX 角色名
【同意的观点】：哪些其他Agent的观点我认同 + 理由
【反对的观点】：哪些我不同意 + 理由 + 反面数据
【补充观点】：其他人忽略的维度
```

### 第三轮：收敛（并行或串行）
投委会主席标注分歧点，要求争议各方做最后陈述。

**输入**：第二轮汇总 + 标注的分歧点
**输出格式**：
```
【席位】：XX-XX 角色名
【立场确认/调整】：坚持原观点 / 部分调整 / 转向
【最终建议】：一句话
【风险警示】：如果我的判断错了，最可能的原因是...
```

### 第四轮：投委会决议（主席单独完成）
投委会主席综合所有输入，形成最终决议。

**输出格式**：
```
【议题】：...
【决议日期】：...

【共识】：（所有Agent一致认同的部分）
- ...

【分歧】：（存在争议的部分 + 各方立场）
- 议题A：MACRO-01认为... vs EQUITY-01认为...
- ...

【决策】：（最终建议）
- 仓位：...
- 方向：...
- 时间窗口：...

【风险预算】：（最大可承受亏损）
- ...

【待验证指标】：（需要持续跟踪的验证信号）
- ...

【下次审议条件】：（什么情况下需要重新讨论）
- ...
```

## 快速流程（两轮制）

适用于时效性强的议题（如突发事件、盘中异动）。

**第一轮**：核心Agent并行输出（简化格式：观点 + 置信度 + 一句话理由）
**第二轮**：主席直接合并出结论

## 特别流程：投资辩论会

适用于重大配置决策，需要基金经理组深度辩论。

**环节1**：配置组给出框架和约束
**环节2**：6位基金经理分别给出组合建议
**环节3**：两两辩论（多头 vs 空头、成长 vs 价值）
**环节4**：主席形成最终配置方案

## 调度语法

投委会主席（用户）可使用以下简写来触发讨论：

| 语法 | 含义 | 调动范围 |
|------|------|---------|
| "召集宏观组" | 宏观组3席并行分析 | MACRO-01/02/03 |
| "召集配置组" | 配置组3席并行分析 | ALLOC-01/02/03 |
| "召集股票组" | 股票组5席并行分析 | EQUITY-01~05 |
| "召集基金经理组" | 6位基金经理辩论 | PM-01~06 |
| "召开投委会" | 全流程四轮讨论 | 全部相关组 |
| "快速研判：XX" | 两轮快速流程 | 相关Agent |
| "辩论：XX" | 投资辩论会 | 基金经理组 + 配置组 |

## 席位组合建议

| 议题类型 | 推荐调动席位 |
|---------|------------|
| 宏观政策变化 | MACRO-01 → ALLOC组 → 股票组相关赛道 |
| 海外突发事件 | MACRO-02 → ALLOC组 → PM-06（风险评估） |
| 行业配置调整 | 股票组对应赛道 → ALLOC-01 → 配置组 |
| 个股投资决策 | 股票组对应赛道 → PM组辩论 → 配置组确认仓位 |
| 市场见顶/见底 | MACRO-03 → PM-06（周期）→ 全体PM |
| 风格切换判断 | MACRO-03 → ALLOC-01 → 股票组全体 |
