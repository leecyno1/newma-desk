# 模块说明（UI Tabs）

> 前端为单文件 SPA：`static/index.html`（内联 CSS/JS），便于快速迭代与本地部署。

## 1) 数据看板

- 关键词：默认从“tool 覆盖后的摘要库”提取，并做去噪
- 近 7 天 KPI：消息数/入站/出站/会议数/活跃联系人/情绪净值
- 图表：ECharts（含词云）+ Plotly（部分图表）

## 2) AI 总结

- 模块化报告：市场观点、会议信息、分歧观点、高评分联系人、新闻舆情、自媒体/公众号/会议聚合摘要
- 结果缓存：刷新页面可恢复上次生成结果（同快照/模块/提示词/温度命中缓存）
- Token 控制：默认走“摘要 + 元数据”链路，避免全文灌入

## 3) 微信聚合

- 数据源：chatlog HTTP 增量/全量（作为主要来源），支持本地 DB 存储与检索
- 筛选：类型/分类/情绪/垃圾/发送人 + 黑白名单（联系人/群聊）
- 互动：顶/踩、约/问/答（用于发送管理任务创建与评分联动）

## 4) 邮件聚合

- 多账户：IMAP 拉取；支持手动同步后刷新列表
- 对齐体验：筛选/表格列与微信聚合一致
- 情绪/分类：与全局情绪算法一致（positive/negative/mixed/neutral）

## 5) 会议聚合

- 纪要来源：本项目 minutes（支持手动新建/导入）
- 本地录音监听：检测音量→自动录音→静音停止→保存音频文件
- 原文查看：弹窗 Markdown 渲染（更易读）

## 6) 新闻聚合

- 内嵌 NewsNow（iframe）
- 配置：功能设置中可保存 NewsNow 基址

## 7) 自媒体聚合

- 数据源：本地 MediaCrawlerPro（结果 JSON）
- 精华筛选：平台/作者/转写状态、最小赞阈值、TopN
- 操作：打开链接、转写（按数据源能力）

## 8) 公众号聚合

- 数据源：本地 we-mp-rss SQLite（articles + article_insights）
- 列：公众号/时间/阅读/转发/赞/在看/标题/摘要/操作
- 详情：可拉取文章全文并弹出查看

## 9) 发送管理

- 左侧：标签/私聊/群聊联系人（支持排序/筛选、Shift 多选、双击建任务）
- 右侧：任务队列（引用原消息 + AI 回复 + 手工编辑 + 批量发送）
- 通道：支持对接 LangBot 网关/WeChatPadPro（以功能设置为准）

## 10) 功能设置

- AI：提示词管理、运行参数（并发/温度）、模块开关
- 聚合参数：自媒体/公众号/会议聚合阈值、录音默认参数
- 黑白名单：联系人 + 群聊维度
- 数据库清理：按时间范围与数据类型清理（危险操作）

## 11) 联系人

- 评分编辑与保存（持久化）
- 与互动联动：顶/踩可加减分；评分 < 40 自动加入黑名单并生效
