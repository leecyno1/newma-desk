# 信息聚合AI系统 Release Notes v0.8.0

发布时间：2025-12-21

## 重点更新

- **AI 总结结果持久化缓存**：同一快照+模块+提示词+温度命中缓存直接返回，刷新页面可恢复上次生成结果。
- **Token 体积控制**：总结链路默认使用“摘要 summary + 少量元数据”的瘦身 payload，避免把长正文/无关字段一并喂给模型。
- **会议路演表格重做**：3 列（时间｜平台/会议号｜主题要点），紧凑行高，禁止横向滚动；主题要点严格取自摘要列并自动换行。
- **新闻舆情来源气泡**：支持在总结文本中通过 `#id` 引用消息/新闻，悬停或点击可查看来源详情；新增 `GET /api/newsfeed/by-ids`。
- **联系人评分与黑名单全链路**：
  - 联系人评分可编辑并保存；消息行“顶/踩”可直接加减分；
  - 评分 < 40 自动加入黑名单（持久化），黑名单联系人/群聊强制从消息列表剔除；
  - 设置页提供黑/白名单可视化管理与候选下拉（含群聊）。
- **邮件页稳定性**：不再首开自动同步/自动切页，仅手动同步后更新列表；黑名单发件人强制从邮件列表剔除。
- **首页加载体验**：后端启用 GZip 压缩，减轻首屏传输压力（尤其是大体积 `static/index.html`）。

## 兼容性说明

- `static/index.html` 为单页聚合 UI（体积较大），建议生产环境使用静态资源压缩与浏览器缓存策略。
- “📅 预约”功能依赖 macOS Reminders（AppleScript），仅在 macOS 可用。

## 已知问题/后续方向

- 邮件黑名单匹配建议对 `Name <a@b.com>` 做邮箱提取归一化，提高命中率。
- 持久化摘要缓存（SyncState）可能随使用增长，建议加入“清空缓存”按钮/清理接口。
