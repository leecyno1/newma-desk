# 量化分析（AI总结）说明

本功能为 AI总结的 `market`（市场观点总结）与 `newswatch`（新闻舆情监测）模块增加“量化分析”段落，用于对每个议题的立场分布进行统计，并以表格 + 进度条形式可视化展示。

## 输出内容

- `## 量化分析`：总览表（议题、样本量、看好/看空/中性占比与计数）
- 每个议题的条形可视化（看好/看空/中性）
- 证据列表：每个立场对应的 `#<id>` 列表（保持可点击徽标与气泡/跳转逻辑）

## 数据口径

- `market`：基于本次分析窗口内的消息摘要（derived.summary 等）形成议题与立场分桶。
- `newswatch`：基于近72小时新闻条目（id/source/title/url/time）形成议题与立场分桶。

## 可点击来源徽标

量化分析中输出的 `#<id>` 会被前端转换为“源”徽标：
- 在 `market` 中：纯数字 `#123` 视为消息ID，支持定位到消息列表。
- 在 `newswatch` 中：`#123` 视为新闻ID，支持弹出气泡并打开原文链接。
