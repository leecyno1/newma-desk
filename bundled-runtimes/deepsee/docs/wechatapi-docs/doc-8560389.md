# 🔄 消息推送事件说明


:::tip[温馨提示]
**消息订阅**：当您需要接收好友消息、群聊变动、或进行各类自动化交互业务时（如根据关键词回复、踢人、拉群等），需要开启消息回调服务。
 WechatApi 会将触发的事件以 **POST application/json** 的形式，实时推送到您配置的接口地址。
:::



<AccordionGroup>
<Accordion title="🛠️  如何配置回调服务" defaultOpen={false} >
  1. **配置路径**：[登录 API 控制台](https://newmanager.wechatapi.net/)，左侧菜单 **【访问控制】 -> 【配置回调地址】**。
2. **全局生效**：设置成功后，该 Token 下登录的**所有微信账号**收到的消息，都会自动推送到您设置的回调接口。
3. **接口要求与规范（必读）**：
    * **公网可达**：回调地址必须发布到公网（临时开发可使用内网穿透工具，但生产环境极易因网络抖动丢失消息）。
    * **快速响应**：您的接口必须在收到请求后的 **3秒内** 返回响应（建议直接返回空字符串 `""` 或 HTTP 200）。超过 3 秒网关将判定为超时并放弃本次推送。建议采用**异步队列**处理实际业务逻辑。
    * **配置验证**：配置保存时，网关会向您的地址发送一条包含文本 `"验证回调地址是否可用"` 的 JSON 测试数据，请确保接口能正常接收并响应。
    * **唯一标识去重**：必须使用`Key=$.Appid + $.Data.NewMsgId`进行消息去重，防止重复处理。
    
**(注：通过 API 接口主动发送的消息不会触发回调，但手机端主动发送的消息会有回调，这属于多端消息同步的 IM 机制。)**
</Accordion>

<Accordion title="🚑  常见问题与排查指南" defaultOpen={false}>

* **微信在线，为什么没有收到消息推送？**
    * 请先使用 Apifox 或 Postman 向您的接收地址主动发送一条测试消息。如果您的接口无法接收，请检查防火墙、网关配置或代码拦截器。如果能收到您的手动测试请求，但收不到微信推送，请联系技术客服协助排查。
* **没找到对应的消息类型怎么处理？**
    * 请使用手机微信，主动向登录了 API 节点的账号转发或发送该类型的消息，然后在您的回调接收端（或后台系统打印日志）查看实际推送的原始 JSON 结构。
* **如何判断这条消息是不是“我自己”发出去的？**
    * 对比消息发送人（`$.Data.FromUserName.string`）与当前微信的设备标识（`$.Wxid`），若一致，则为本账号发出的消息。
* **如何判断消息是不是发在群里的？**
        * 别人发的：发送人（`$.Data.FromUserName.string`）以 `@chatroom` 结尾。
        * 自己发的：接收人（`$.Data.ToUserName.string`）以 `@chatroom` 结尾。
* **如何提取群聊消息的真实发送者（谁在群里说的话）？**
    * 群消息的 `Content.string` 会被特殊拼接，格式通常为：`"wxid_xxxx:\n这个是消息内容"`。您可以通过切割冒号换行符（`:\n`）前的第一段内容，提取出真实发言人的 `wxid`。
</Accordion>
</AccordionGroup>

## 📦 核心事件速查表

> 消息类型判定路径：先判定外层 `TypeName`，如果是 `AddMsg`，再判定内层 `MsgType`。

### 1. 基础消息 (`TypeName: AddMsg`)

| 消息类型 | `MsgType` | `$.Data.Content.string` (核心内容) |
| :--- | :--- | :--- |
| **文本消息** | **1** | 文本正文 |
| **图片消息** | **3** | 图片 CDN XML (可免上传直接用于【[图片转发](https://post.wechatapi.net/message/forwardimage)】) |
| **语音消息** | **34** | [语音下载](https://post.wechatapi.net/message/downloadvoice) XML |
| **好友请求** | **37** | 申请人验证信息 (可用于【[自动同意](https://post.wechatapi.net/contacts/addcontacts)】接口) |
| **名片消息** | **42** | 被推荐人信息 (可用于[主动加人](https://post.wechatapi.net/contacts/addcontacts)) |
| **视频消息** | **43** | 视频 CDN XML (可免上传直接用于【[视频转发](https://post.wechatapi.net/message/forwardvideo)】) |
| **Emoji表情**| **47** | 表情 XML (含 MD5) |
| **地理位置** | **48** | 位置 XML (可直接[转发位置](https://post.wechatapi.net/message/postlocation))|

### 2. 复合/应用类消息 (`TypeName: AddMsg` , `MsgType: 49`)
⚠️ 当 `MsgType = 49` 时，必须解析 `Content.string` 中 XML 的 `msg.appmsg.type`：

| 业务分类 | `appmsg.type` | 备注说明 |
| :--- | :--- | :--- |
| **公众号/文章链接** | 5 | 需结合 XML title 区分是否为群邀请链接 |
| **文件就绪(可下载)**| 6 | 文件已发送完毕，可执行[下载](https://post.wechatapi.net/message/downloadfile)或[转发](https://post.wechatapi.net/message/forwardfile) |
| **小程序卡片** | 33 或 36 | |
| **引用回复消息** | 57 |引用消息回复参考[发送APPMSG消息](https://post.wechatapi.net/message/postappmsg) |
| **文件发送中(提示)**| 74 | 仅提示对方在发文件，此时**不可下载** |
| **微信转账** | 2000 |仅提醒 |
| **微信红包** | 2001 |仅提醒 |

### 3. 系统与通知指令 (`TypeName: AddMsg` , `MsgType: 10000 / 10002`)
⚠️ 此类消息需配合解析 `Content.string` 文本或 XML (`sysmsg.type`) 判断：

| 指令类型 | 判断条件 |
| :--- | :--- |
| **消息撤回** | `MsgType = 10002` 且 `sysmsg.type = revokemsg` |
| **拍一拍** | `MsgType = 10002` 且 `sysmsg.type = pat` |
| **群变动** | `sysmsg.type` 为 `mmchatroombarannouncememt`(公告) 或 `roomtoolstips`(待办) |
| **群管理** | 被移出群聊/修改群名 (`MsgType=10000`)；解散/踢人 (`MsgType=10002`+`sysmsgtemplate`) |

### 4. 账号与联系人变动 (独立 `TypeName`)

| 变动事件 | `TypeName` | `Data` 数据说明 |
| :--- | :--- | :--- |
| **资料变更/加粉成功** | `ModContacts` | 返回包含昵称、性别、地区的完整 Profile 对象 |
| **删好友/退出群聊** | `DelContacts` | 包含 `UserName` 对象 (wxid 或 @chatroom) |
| **⚠️ 节点掉线告警** | `Offline` | 节点离线。**需立即告警并重新扫码登录** |

### 5. 视频号专属事件
| 事件 | `TypeName` | 处理建议 |
| :--- | :--- | :--- |
| **互动(点赞/评论)**| `FinderSyncMsg` | 收到通知后，调用【[获取消息列表接口](https://post.wechatapi.net/finder/mentionlist)】查详情 |
| **收到私信** | `FinderBypMsg` | 同上 |

```json
// 通用回调结构壳
{
    "TypeName": "AddMsg",      // 顶层事件类型
    "Appid": "wx_xxxxxxxx",    // 设备标识
    "Wxid": "wxid_xxxxxx",     // 接收此消息的微信端
    "Data": {                  // 消息主体 (根据 TypeName 和 MsgType 变化)
        "NewMsgId": 1234567,
        "MsgType": 1,
        "FromUserName": { "string": "wxid_sender" },
        "ToUserName": { "string": "wxid_receiver" },
        "Content": { "string": "消息正文/XML数据" }
    }
}
```
