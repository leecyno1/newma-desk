# 🛡️ 账号风控与安全运营指南



:::caution[使用规范]

无论是构建复杂的自动化系统，还是驱动 AI Agent，**账号本身的健康度（权重）是所有业务的基石**。微信拥有一套极为严密的基于行为学与环境特征的风控模型。为了保障您的业务持续稳定运行，请务必在接入本 API 前，仔细阅读并严格执行以下账号预热与运维规范。
:::




## 🟢 一、 基础环境与网络规范 (基建期)

账号的生存率很大程度上取决于注册与运行的物理/网络环境。

### 1. 实体卡与设备选择
* **拒用虚拟号段**：严禁使用 170、171、165 等虚拟运营商号段注册，此类号段在微信风控库中初始信任度极低。
* **规避风险卡源**：谨慎购买网络渠道的二手回收手机号，极易存在历史违规记录导致的“连坐”风险。
* **一机一号原则**：严禁使用系统自带的“应用分身”或第三方多开软件（如各种非官方客户端）。必须保证在原生官方 App 中进行初始注册。

### 2. IP 与网络隔离隔离策略
* **注册环境**：新注册账号必须使用**移动网络（4G/5G 流量）**，切勿使用公共 WiFi。
* **防批量风控**：同一个手机设备当天最多注册 2 个账号；同一个 IP 地址（尤其是 WiFi 环境下）当天最多注册 5 个账号。严禁同时间、同定位、同号段进行批量注册操作。

## 🟡 二、 新账号预热与权重提升 (0-15天高危期)

刚注册的新号属于“沙盒观察期”，风控容忍度极低。此阶段**严禁直接接入 API 进行任何自动化或营销操作**，必须完全模拟真实人类行为。

### 1. 身份特征完善 (Day 1)
* **完善基础档案**：设置高质量去同质化的头像、昵称、性别、地区和个性签名。
* **极高权重操作**：完成**实名认证**并**绑定本人实名银行卡**（存入小额资金）。微信对涉及实名资产的账号封禁尤为慎重，这是防封的绝对核心。

### 2. 真实社交图谱构建 (Day 1-7)
* **高权重好友互聊**：主动添加 3-5 个“高优老号”作为常聊好友（要求：注册半年以上、实名绑卡、近期无封号记录），这批人将作为未来可能的“辅助解封人”。
* **日常行为模拟**：使用语音、图片、文字与老好友进行正常沟通。每天不定期刷朋友圈、阅读公众号文章（建议关注并阅读“微信安全中心”）。
* **支付行为多样化**：使用该账号进行微小额度的真实消费（如：扫码买瓶水、微信支付打车、捐赠 1 元公益等）。

### 3. 操作红线 (前15天绝对禁止)
🚫 更换设备登录。
🚫 使用任何营销功能（附近的人、摇一摇、建大群）。
🚫 批量发送链接、名片或商品交易信息。

## 🔴 三、 核心风控触发机制与规避策略

当您的账号预热完成并接入 WechatApi 后，在调用接口时需严格规避以下行为红线。

### 1. 致命操作 (极易触发永久封禁)
* **高频涉赌涉非行为**：24小时内发送红包超过 100 次（受限）或 200 次（必封）。
* **底层环境污染**：在运行 API 的设备上同时安装了抢红包插件、虚拟定位等非法外挂软件。
* **新号秒发大招**：注册不足 2 个月的新号，刚登录节点就开始批量拉群、海量群发。

### 2. 异常行为 (易触发限制社交功能)
* **无延迟的机器行为**：通过 API 每分钟向超过 15 位不同好友发送消息。**（建议：接入 AI 或自动化逻辑时，代码中务必加入 3-5 秒的随机延迟，模拟真实输入速度）**
* **单向强加好友**：频繁发送好友请求。每天对同一人申请勿超 2 次；每天主动添加陌生人勿超 5 次，且需拉长间隔。
* **群发炸群**：连续高频群发相同内容的公告。建议采用少量多次的策略（如：每半小时分发 50 人）。

## 🚑 四、 账号冻结与辅助解封指南

若由于业务逻辑失误导致账号被风控限制，请保持冷静，按照官方流程进行申诉与解封。

### 1. 解封前置条件 (需寻找符合条件的好友)
协助您解封的微信账号必须满足以下**全部硬件条件**：
1.  已绑定手机号及实名银行卡。
2.  账号注册时间超过 6 个月，且当前无异常状态。
3.  **额度限制**：该辅助账号 1 个月内未帮他人辅助过；6 个月内辅助次数不超过 2 次；1 年内不超过 3 次。
4.  该辅助账号近期未被封号，且未被其他人邀请辅助中。

### 2. 标准解封流程
1.  **提交申请**：在被限制的账号上按照系统弹窗指引，进入解封流程，并输入愿意协助您的“好友手机号”。
2.  **好友辅助**：通知该好友打开微信，搜索并关注官方公众号 **【微信团队】**。
3.  **确认身份**：好友点击左下角 `自助工具` -> `辅助验证` -> `协助好友验证`。
4.  **完成验证**：核对信息并确认“是他本人联系我”，完成安全校验后即可解封。

*(注：如果在提交阶段输错了辅助人的手机号，系统会限制 1 小时后才能重新发起申请，请务必核对准确。)*
