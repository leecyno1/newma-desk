# 对接步骤

对接步骤
#### 步骤1：开通API接口权限
点击右上角API接口后台，进入[API后台](https://newmanager.wechatapi.net/)，点击套餐购买，立即免费试用7天。


![image.png](https://api.apifox.com/api/v1/projects/4153824/resources/430779/image-preview)

#### 步骤2：复制toKen,填写回调地址
兑换成功后，点击访问控制，填写消息回调地址。复制TokenId



![image.png](https://api.apifox.com/api/v1/projects/4425884/resources/501112/image-preview)



#### 步骤3：调用Api接口
打开API文档，携带TokenId参数即可进行登录模块代码接入，登录成功后，即可根据业务调用对应接口开发各类业务。
> 登录步骤为：获取二维码登录，执行登录两个接口按顺序执行。


![image.png](https://api.apifox.com/api/v1/projects/4425884/resources/501116/image-preview)
