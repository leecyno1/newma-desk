## 命名规范说明

### 格式
```
数字(1-9) + 评级(a-e) + 姓名 + 单位 + 其他信息
```

### 数字（重要程度）
- 1-2: 非常重要（高频联系）
- 3-4: 较重要（中高频联系）
- 5: 中等重要（正常联系）
- 6-7: 较不重要（低频联系）
- 8-9: 不重要（极少联系）

**判断依据**: 消息记录数量
- 50+ 条消息 → 3
- 20-50 条消息 → 4
- 5-20 条消息 → 5
- < 5 条消息 → 6

### 评级（质量/价值）
- a: 优秀（80-100分）
- b: 良好（60-79分）
- c: 中等（45-59分）
- d: 一般（30-44分）
- e: 较差（0-29分）

**判断依据**: contacts 表中的 rating 字段

### 信息补充原则
- **姓名**: 从原始名称提取
- **单位**: 从聊天记录中提取公司/机构名称
- **其他信息**: 职位、微信号、备注等
- **未知填充**: 无法获取的信息统一标记为"未知"
