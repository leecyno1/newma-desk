# 信息聚合AI系统（Dr.Lemon）概览

本项目是一套“本地优先”的信息聚合与分析系统：把微信/邮件/新闻/自媒体/公众号/会议纪要等多源信息收敛到同一个 UI 中，做统一筛选、AI 总结与发送管理，减少在多个系统之间来回切换。

## 适用场景

- 投研/公关/产品/运营：快速把握近 1 天/3 天/7 天的“重要变化”与风险提示
- 会议纪要：录音→转写→原文梳理→摘要（支持手动导入/粘贴作为补充）
- 多源聚合：公众号/自媒体高质量内容“精华筛选”（按高赞/阈值）
- 回复与发送：从“约/问/答”生成任务，AI 生成候选回复并批量发送

## 核心优势

1) **多源统一视图**
- 微信聚合、邮件聚合、新闻聚合、自媒体聚合、公众号聚合、会议聚合都用一致的筛选/表格交互

2) **Token 体积控制**
- AI 总结链路默认使用“摘要 summary + 少量元数据”的瘦身 payload，避免把长正文/无关字段一并喂给模型
- 关键词看板默认也从“tool 覆盖后的摘要库”提取（并去噪）

3) **本地优先 & 可扩展**
- 数据落地 SQLite，适合本地/私有部署
- “自定义聚合”支持按适配器配置生成动态标签页，为未来接入 LangBot 多平台消息与记录做铺垫

## UI 模块一览

- **数据看板**：关键词、趋势、分布等指标（浅/深色主题）
- **AI 总结**：按模块生成报告（支持恢复上次结果）
- **微信聚合**：消息检索/筛选、顶踩/约问答、黑白名单生效
- **邮件聚合**：多账户 IMAP 拉取 + 筛选；摘要/原文查看
- **会议聚合**：本地会议录音监听 + 纪要列表；支持新建/导入
- **新闻聚合**：内嵌 NewsNow 页面
- **自媒体聚合**：读取本地 MediaCrawlerPro 结果，精华筛选与链接跳转
- **公众号聚合**：读取本地 we-mp-rss SQLite（含 insight summary）
- **发送管理**：联系人选择、任务创建、AI 生成、批量发送
- **功能设置**：提示词/通道/聚合参数/黑白名单/数据库清理等
- **联系人**：评分编辑与保存，评分<40 自动拉黑（持久化）
