# Security Policy

## 不应进入仓库的内容

- API 密钥、访问令牌、飞书或平台凭证
- Cookie、浏览器 Profile、命名账号 Session
- OTP、短信验证码和二维码登录材料
- 未脱敏的账号清单、抓取快照和发布回执
- 成品视频、音频、模型、缓存、虚拟环境和 `node_modules`

请使用 `.env`、系统钥匙串或仓库外配置目录。公开示例只能包含明显的占位符。

## 报告问题

请不要在公开 Issue 中粘贴凭证或账号数据。可先提交不含敏感内容的安全问题说明，并请求私下沟通渠道。

## 已进入历史的凭证

一旦凭证被提交到公开 Git 历史，应立即视为泄露：

1. 在服务提供方轮换或撤销凭证。
2. 从当前快照和完整 Git 历史中移除对应文件。
3. 对所有远端执行受控的历史重写推送。
4. 通知协作者重新同步已重写的分支。

仅删除工作区文件或增加 `.gitignore` 不能消除历史泄露。
