## 结论

| 候选 | 决策 | 导演/运营价值 | 当前可用性 | 下一步 |
|---|---|---|---|---|
| `video-shotcraft` | 高优先级储备 | 镜头配方、真实页面采集、2.5D 运镜、节奏卡点、SFX、独立终审 | 本机 catalog 有标准 Skill，尚未接入 Newma | 建立适配器并做一条 Remotion 冒烟样片 |
| `gsap-skills` | 高优先级套件储备 | HTML 动画、时间轴、SVG、React、性能与响应式动效 | 本机 catalog 有 8 个官方 Skill | 导演只登记一个 Suite，内部再分派子 Skill |
| `impeccable` | 中高优先级储备 | HTML 分镜、动态图表、标题系统、响应式与浏览器视觉质检 | 本机 catalog 有标准 Skill | 作为发布前视觉 QC 顾问接入，不替代现有设计审查 |
| `taste-skill` | 已有能力，拒绝重复 | 视觉品味、版式、反模板感审查 | 已安装为 `design-taste-frontend` | 保持现状 |
| `video-autopilot-kit` | 高优先级待封装储备 | 短视频脚本、CapCut JSON、FFmpeg 模板、批量生产 | 无标准 `SKILL.md`，当前项目未克隆 | 先克隆审查，再做受控适配器与输出路径保护 |

## 未纳入可执行储备

- `governed-dcf-skill`：金融方法论本身有价值，但和视频生成、自媒体运营的直接关联较弱，且未声明许可证。
- Livo REDSkill / p5.js 附件：未核实稳定公开上游与许可证；通用程序化动效已有 `algorithmic-art` 与 GSAP 路线覆盖。

## 路由原则

- 储备候选永远不能成为导演主路由；只有完成适配、依赖检查、冒烟测试和人工复核后才能晋级。
- GSAP 八个子 Skill 不作为八个同级导演入口，防止路由噪音。
- `video-shotcraft` 借鉴镜头语言和审查机制，但 Newma 的口播主线、事实证据、真实素材与画幅规范仍是最高约束。
- `impeccable` 用于 HTML 画面和动态图表的视觉验收，不替代 `design-taste-frontend`、`review-animations` 或渲染技术质检。
