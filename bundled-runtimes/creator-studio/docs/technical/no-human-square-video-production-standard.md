# 无真人财经视频正式生产标准

状态：`canonical`
适用范围：`explainer_html_video`、`vox_explainer_video`、财经/产业无头口播、正式发布版

说明：文件名为历史兼容路径。当前默认母版已恢复为横版 `16:9`；`1:1` 和 `9:16` 作为独立发布适配规格保留。

## 1. 正式合成栈

正式版采用分层合成，不允许把一种工具机械地分配给一个镜头：

```text
真实视频素材
  -> live HTML Video 场景（布局、视频底层、图表主体、场内运动）
  -> Remotion 主时间轴（帧级图表提示、字幕、转场、音频与总合成）
  -> FFmpeg/QC（探测、响度、封装与交付校验）
```

- HTML 场景必须通过浏览器实时录制；禁止 PNG 拼接、静态截图时间轴和 `zoompan`。
- Remotion 必须承担实际可见的帧级工作，如数据图表、局部标注、字幕、进度或主时间轴合成，不能只作为空壳封装器。
- 同一分镜可以组合真实视频、HTML/SVG/GSAP、Remotion 图表、字幕和声音；导演按解释目标路由，不按工具数量拆镜头。
- `vox_explainer_video` 必须额外包含一个中心问题、3-6 个证据支柱、反证或边界条件和有限结论；不得仅把普通无头口播换成资料拼贴风格。
- 场景已自带明确运动设计时，正式录制应关闭通用扫光、扫描线或环境 sweep 注入，避免模板效果覆盖导演意图。

## 2. 画幅合同

- 无真人财经默认母版：`1920x1080`、`30fps`、`yuv420p`、`16:9`。
- 方形适配版：`1080x1080`；竖版适配版：`1080x1920`。适配版必须重新布局，禁止拉伸母版。
- 横版默认安全区：左右至少 `96px`、顶部至少 `64px`、底部字幕区至少 `150px`。
- 标题、证据图表和字幕不能争夺同一区域。字幕一般置于底部安全区，图表完成态不得被字幕遮住。
- 真实视频进入不同画幅时使用主体感知裁切；不能拉伸。多视频宫格各自使用 `object-fit: cover`，并保持可识别主体。
- 真实视频只有在最终画面中持续可见时才计入真实素材占比；被全不透明面板完全遮住的不计入。

## 3. 开场与真实视频连续性

- 开场默认使用：`真实视频底层 + 动画标题 + 问题地图/大纲 + 互动数据 + 完整字幕`。
- 4-6 分钟产业/财经视频目标：下载 10-18 个候选，保留 6-12 个可用片段，覆盖至少 4 类视觉语义，并在 6-12 个窗口中使用真实视频。
- 真实视频应贯穿开场、机制解释、章节桥、计算场景和结尾；允许复用同一素材家族，但必须改变时间段、裁切、遮罩、色彩和叠加语法。
- 真实视频默认是情境证据。无尘室、交易屏或发布会画面不能直接证明估值、成交额、监管规则或收益率。

## 4. 图表与证据

- 来源图表先做原始尺寸审计。展示截图时必须先完整 `contain`，再局部聚焦，最后回到完整状态。
- 数据可以完整重建时，优先显示数据驱动的动态 HTML/Remotion 图表；不要同时重复原截图。
- 原图与正文数字冲突时，不能择一静默使用。必须记录冲突，排除错误或不一致的图片，并从已批准事实底板重建。
- 枚举数量必须贯穿口播、分镜、渲染和总结。例如原文有 5 点，最终画面必须完整显示 5 点。
- 图表完成态要保留足够阅读时间；不能为了增加切换密度而用关键词卡遮住核心图表。

## 5. MiniMax 声音主时间轴

- 正式配音使用 MiniMax CLI：`speech-2.8-hd`、`tianxin_xiaoling`、默认 `1.2x`。
- 优先逐场生成语音并请求供应商字幕时间，场景时长由真实音频时长驱动。
- 逻辑场、证据场、章节和总结可分别追加约 `0.35s`、`0.45s`、`0.50s`、`0.60s` 的语义尾帧；禁止用多秒静音硬撑原估时。
- 供应商只返回句级时间时，可以在句级时间窗内按语义短语拆分字幕；必须保留供应商句级边界，不得重新按全文字数估时。
- 屏幕字幕使用阿拉伯数字增强可读性，TTS 文本保留自然中文读法。
- 运行前检查 MiniMax 服务地址。CLI 会自动追加 `/v1` 时，`MINIMAX_BASE_URL`/`base_url` 必须是服务根地址，禁止配置成带 `/v1` 的地址导致 `/v1/v1/...`。

## 6. 发布前门禁

以下条件全部满足才允许标记为正式成片：

1. `storyboard_review_gate.render_allowed == true`。
2. Claim/Evidence 门禁通过，观点和概率判断有屏幕披露。
3. HTML 场景是实时录制，通用扫光注入已按导演设计关闭或明确批准。
4. Remotion 图表/字幕/主时间轴在成片中真实可见。
5. 字幕覆盖完整口播并由真实音频时间驱动。
6. 母版输出为 1920x1080、30fps、H.264/AAC；适配版按已批准画幅单独渲染，音画时长一致。
7. 抽查开场、核心图表、真实视频宫格、字幕密集点和结尾，不存在裁图、穿模、遮挡或开发标签。
8. 真实素材版权状态已人工复核；未复核素材只能保留为待发布风险项，不能误报为版权已通过。

## 7. 交付目录

正式项目保持浅层结构：

```text
video_director/
assets/
audio/
scene_pack/
remotion/
renders/
qc/
delivery/
```

`delivery/final_delivery_manifest.json` 必须登记终片、字幕、配音、配乐、封面、QC 报告、分镜批准文件、来源清单、尺寸、时长和哈希。
