# 2026-08-10 VOX 小红书样片学习

## 样片结论

| 样片 | 学到的核心方法 |
| --- | --- |
| 小白三步做 VOX | 口播文案先生成风格板；风格板固定配色、材质、字体；再拆分镜并生成每镜头提示词。 |
| Google Flow VOX | 先生成完整首帧，在统一纸张世界中让地形、建筑和物件逐层立起，镜头沿路线运动。 |
| AI 公式化复刻 VOX | 风格板不是终片，而是所有分镜的视觉合同；同一风格板配合不同画面描述生成统一镜头。 |
| 一键 VOX 成片 | 连续纸张立体世界、重复主角和道具、实体化数据、机械装配与相机跟随共同建立连贯性。 |
| VOX Skill 教程 | 文案交给 Codex 设计世界、关键物件和组装顺序；生成起始帧、结束帧和运动提示词，再用帧模式生成短 B-roll。 |
| AIGC 图生视频 VOX | 用一个 Skill 把脚本同步拆成生图提示词和视频提示词；参考母图锁定风格，前置提示词控制迁移；视频提示词同时给出时长和音效建议。 |

## 对旧黄金样片的诊断

旧样片的调查结构正确，但视觉仍属于普通无头口播：九个大场景分别切换到标题、逻辑框、白底图表和 PIP。它缺少以下 VOX 核心：

1. 没有先建立视觉圣经。
2. 没有统一的空间世界和重复物件。
3. 每段旁白只有一个主构图，缺少 2.5-5 秒微分镜。
4. 图表替换了画面，而不是成为画面里的证据物件。
5. 缺少起始帧、结束帧和运动提示词合同。

## 新第三链路

`中心问题 -> 证据地图 -> VOX 视觉圣经 -> 微分镜 -> Claim/Evidence -> 起止关键帧与真实素材 -> 选择性生成运动底片 -> vox-editorial-collage Remotion 主时间轴 -> 全片 QC`

### VOX 视觉圣经

- 材质：撕边报纸、纸板厚度、胶带、印章、红线、剪纸人物与物件。
- 色彩：墨黑、米黄、信号红、证据青、黄金色。
- 空间：同一张证据桌或纸张立体世界。
- 动作：物件组装、路径生长、纸张撕裂、数据实体化、镜头跟随与拉远总览。
- 证据：真实新闻、访谈、文档和数据以贴纸屏幕、报纸页、电视框或纸张图表进入世界。

### 生成策略

- 默认由 Remotion 生成连续纸张世界、物件和数据动画。
- 重点镜头可使用“起始帧 + 结束帧 + 运动提示词”生成 3-8 秒运动底片。
- 生成式镜头只承担解释和过渡，不能冒充新闻、访谈、历史资料或数据证据。
- Remotion 始终是主时间轴，负责真实素材、运动底片、字幕、来源和声音的最终合成。

## 第六条样片：值得吸收与必须舍弃

样片时长 106.1 秒，画面变化密度约 32.23 次/分钟。真正有价值的不是某个画风，而是它把生成任务压缩成一个稳定的数据包：

1. 一段脚本同时产出 `image_prompt` 和 `motion_prompt`。
2. 一张参考母图负责约束整组镜头的材质、构图和色彩。
3. 前置提示词规定如何参考风格，正文提示词只描述本镜头内容。
4. 视频提示词根据旁白长度给出目标时长，并附带音效建议。
5. 完整画面先生成，再做局部镜头运动、红线路径、物件激活和纸张组装。

需要舍弃的问题：样片在 74.67 秒出现约 0.37 秒黑场，并检测到多次低亮度入场脉冲。因此第三链路只吸收“参考母图 + 双提示词 + 时长 + 音效”的生成合同，最终拼接仍由 Remotion 执行，并继续执行闪屏门禁。
