# 广告创意合同

## 模式选择

| 模式 | 主要目标 | 默认结构 | 推荐时长 |
| --- | --- | --- | --- |
| `brand_film` | 建立品牌印象与情绪认同 | 情绪钩子 → 品牌承诺 → 场景/价值 → 证明 → 品牌记忆 → CTA | 30/60 秒 |
| `product_promo` | 让用户看懂产品价值 | 痛点 → 产品承诺 → 功能演示 → 用户收益 → 证明 → CTA | 15/30/60 秒 |
| `launch_trailer` | 制造新品发布期待 | 悬念 → Reveal → 核心升级 → 使用结果 → 上线信息 → CTA | 15/30/60 秒 |
| `performance_ad` | 点击、留资、下载或购买 | 直接痛点 → 承诺 → 卖点 → 证明 → Offer → CTA/免责声明 | 15/30 秒 |

## 最小输入

- `title`
- `mode`
- `brand`
- `product`
- `audience`
- `objective`
- `duration_sec`
- `aspect`
- `hook`
- `pain`
- `promise`
- `benefits`
- `proof`
- `brand_memory`
- `cta`
- `brand_tokens`

`benefits` 与 `proof` 可使用字符串，或包含 `text`、`on_screen`、`evidence_refs` 的对象。

可选字段：

- `offer`
- `disclaimer`
- `brand_assets`
- `product_assets`
- `source_materials`
- `voice`
- `allow_generated_brand_visuals`
- `platforms`

## 文案规则

- 钩子只负责让目标用户停下，不要同时塞入所有卖点。
- 产品承诺写用户获得的结果，功能名放到后续演示。
- 每个卖点只表达一个动作与一个收益。
- Proof 必须回答“为什么相信”，不能用空泛的“领先、专业、智能”。
- CTA 只保留一个主动作；关注、下载、购买、预约、咨询不能同时抢主位。
- 屏幕文案通常不超过 12 个中文字符；法律说明除外。

## 素材真实性

| 素材 | 可承担的作用 | 不可承担的作用 |
| --- | --- | --- |
| 官方产品录屏/实拍 | 产品功能、流程、外观与结果 | 超出可见范围的性能结论 |
| 官方页面/价格页 | 页面中明确写出的价格、规则、功能 | 未显示的长期承诺 |
| 客户案例/数据 | 对应案例与明确口径的结果 | 泛化为所有用户必然结果 |
| 情境 B-roll | 使用场景、情绪、行业环境 | 证明产品真实功能或收益 |
| 生成式画面 | 概念、氛围、隐喻、转场 | 真实产品 UI、客户证言、价格和效果证明 |

## 视觉与声音

- 每个项目先锁定 Logo、主色、辅助色、字体、圆角/线条、影像材质和运动情绪。
- 真实产品镜头是视觉锚点；高辨识度动效只用于 Hook、核心 Reveal、Proof 和 CTA。
- 多场景 HyperFrames 必须有进入动画和明确转场，不允许无过渡跳切或无限循环。
- Remotion 只挂载一条主旁白；BGM 独立连续铺设并在人声下 duck。
- 字幕来自真实音频时间戳或强制对齐；花字强调承诺、关键数字、Offer 和 CTA，不复制整句字幕。

## 审核问题

1. 目标用户在前 3 秒知道这条广告与自己有什么关系吗？
2. 产品是否在承诺之后尽快出现？
3. 每个卖点是否有对应演示、数据或可信证明？
4. 生成画面是否可能被误解为真实产品或真实客户结果？
5. 品牌记忆点和 CTA 是否能在静音观看时仍被识别？
6. 价格、优惠、日期、限制条件和免责声明是否准确？
7. 去掉 Logo 后，这条片子是否仍然有独特的品牌视觉？
