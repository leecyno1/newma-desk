# 质量门禁

## 导演门禁

- 必须先有独立重写后的 `narration_script.rewritten.md`；文章章节摘要、逐段复述或原文轻度改写不算剧本重写。
- `script_rewrite_gate.json` 未通过时，只能修改口播和证据结构，不能批准分镜或拆生产镜。
- 默认采用核心覆盖表，不逐段映射公众号文章；逐段稿仅在用户明确要求时用于查漏。
- 前 8 秒必须有明确钩子，并在后文兑现。
- 博主介绍必须位于第一条有效信息之后，且只用一句话。
- 每 45–60 秒至少一次推动叙事的互动、预测、比较或认知刷新；空泛的“你怎么看”不算互动。
- 至少两次阶段性答案、反转或认知刷新，并包含一个可信反方观点或边界条件。
- 每个关键数据后必须解释量级、比较对象和“意味着什么”。
- 审核稿使用 10–25 秒 `story_segment`，展示完整口播、证据、画面、花字、实体标签和留存作用。
- 用户未批准重写口播和审核分镜前，不得拆 8–12 秒生产镜、锁视觉圣经或生成素材。
- 审批后每个 `director_shot` 必须回指所属叙事段、核心观点和证据；拆镜不得改变已批准结论。

## 分镜与参考图

- 一个导演镜头承载一个清楚的视觉命题，目标 8–12 秒。
- 先锁视觉圣经，再批量生成参考图。
- 参考图仅用 Codex `imagegen`：16:9、扁平纸拼贴、4–6 个大组、边界清楚、留足空隙。
- 图片内不要放可读文字、数字、签名、Logo、仪表刻度或精确图表。
- 参考图接触表必须人工通过，才允许消耗视频生成额度。

## Shotcraft 镜头

- 只能在口播和审核分镜批准后绑定，绑定不得改变已批准的论点和证据关系。
- 每镜必须写明 `shotcraft_card`、`style_key`、`card_source`、`demo_source`、`duration_frames`、视觉圣经可用时的 `brand_tokens`，以及至少两个 `qa_frames`。
- 多样式卡不得省略 `style_key`；`demo_source` 必须位于对应卡片声明的 demo 目录。
- 真实网页和文档必须有 2× 全页图、元素切片和 `layout.json`；实际页面不得用 AI 伪造。
- 实现必须继承视觉圣经，不得直接套用 Ink Press 的纸墨皮肤。
- 禁止 `Math.random()`、`Date.now()` 和无参 `new Date()`；伪随机使用固定种子。
- 同一种高辨识度卡片默认只做一次主角；重复使用必须改变叙事作用和构图。
- 终检对照动作语法、关键时值和卡片已知坑，不要求与 Gallery 像素级一致。

## 单镜视频

自动抽取首帧、中帧、尾帧和等距接触表，逐镜判断：

- 首帧无黑白闪屏；背景/底板连续可见。
- 中段无新增物件、融化、重复、伪文字、全画面漂移或无意义推拉。
- 尾帧稳定，构图接近参考图，关键物件未越界。
- `assemble` 失败时只将该镜改成 `in_place`；不要重做已经通过的镜头。
- 自动检测只能筛异常，视觉语义仍需导演抽查。

## Remotion 二剪

- 字幕使用原旁白或 ASR 的词级/句级时间轴，不能用十秒镜头摘要代替，也不能按文字长度平均分配时间。
- 每条字幕必须带 `startMs`、`endMs` 和 `timingSource`；优先 `asr-aligned-to-script`，字幕与实际发音明显错位时不得交付。
- 每个中心判断、反转、关键数字或结论落点至少规划一条 `emphasis_cues` 花字。花字只提炼 2–8 个字，不重复整句字幕，并与对应发音同时出现。
- 人物、机构、地点和叙事关键物件首次出现时增加 `entity_labels`。例如央行建筑旁标“央行”，人物旁标真实姓名；标签跟随物件出现，靠近但不遮挡主体、字幕或证据。
- 所有花字和说明标签只在 Remotion 生成，禁止让生图或视频模型烘焙文字。
- 标题、数字、日期、引用、新闻截屏、真实图表和来源标签只在 Remotion 加。
- 生成视频作为 B-roll/解释层，不得冒充真实新闻、采访、历史记录或精确证据。
- 相邻镜头优先干净切；需要叠化时只预叠 3–4 帧。
- SFX 一律使用 `SHOTS.<id>.from + offset` 或 `beatF(n)` 相对钉帧，禁止裸绝对帧号。
- 统一 1920×1080、30fps；旁白、字幕、BGM、原声和证据层在最终时间轴对齐。

## 成片 QC

- 全片扫黑帧、白帧、异常冻结、单帧闪屏和字幕尾部越界。
- 抽查字幕开始/结束点是否贴合发音，重点句是否有花字，所有新人物和关键贴纸是否有正确说明标签。
- Shotcraft 镜头抽查 `qa_frames`，并核对真实页面文字锐度、卡片落位和 PageCam 纵深是否穿帮。
- 在每个切点与字幕结束点前后抽查 7 帧。
- 最终交付文件必须与 QC 通过的文件路径、时长和哈希一致。
