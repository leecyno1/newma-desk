# 数字人口播路线选择

更新于 2026-08-13。

## 结论

正式主路线改为：

`Codex imagegen 写实动物换头 → Luma Dream Machine 音频驱动口型 → Remotion 二剪`

原因是该路线先生成完整一致的角色照片，再由视频模型统一生成头、颈、身体和手部运动，不会出现 Inochi2D 全身贴纸或脖子硬拼接。

## 路线比较

| 路线 | 画面能力 | 主要问题 | 定位 |
| --- | --- | --- | --- |
| imagegen + Luma | 完整写实换头、口型、微表情、身体与手部微动作 | 需要登录和生成额度；长片需分段 | 当前主路线 |
| JoyVASA + LivePortrait | 单图加音频，本地运行 | 实测瞪眼、木偶感、嘴型不稳 | 完全离线备用 |
| Inochi2D + OpenSeeFace | 固定 2D rig、实时跟踪 | 需专属 rig；不适合把全身角色直接贴到真人身上 | 仅研究/直播角色 |
| EchoMimic V2/V3 | 半身动作更丰富 | 依赖 NVIDIA/CUDA 和较大模型 | CUDA 实验档 |
| Wav2Lip/VideoReTalking | 已有视频的口型修复 | 不能从照片生成身体动作 | 修复工具 |

## 动物造型优先级

1. 大猩猩：人形颅骨和嘴部结构最接近人类，口型稳定性通常最好。
2. 牛：角色辨识度强，但长口鼻可能放大口型误差。
3. 马：喜剧效果强，口鼻更长，必须先审嘴部畸变。
4. 戴头套真人：身体一致性最好，但需要确认 Luma 是否能从头套开口生成可信口型。

## 生产策略

- 换头图先审，再消耗 Luma 额度。
- 首次只做 6–10 秒，固定镜头、正脸、克制动作。
- 用同一张换头源图、同一提示词和同一角色描述生成所有段落。
- Luma 只负责视觉；MiniMax 音频始终是最终母带。
- 句号、换题和证据全屏处切段，不在词中间切。
- 每段生成后检查首帧、中帧、尾帧和音画同步。

## 回退边界

Luma 无法登录、额度不足或短样连续失败时，先停下并让用户决定：

- 改用 JoyVASA 完全本地备用；
- 改用已有真人口播视频做动物换头/视频到视频；
- 或等待 Luma 恢复。

不得自动切回 Inochi2D 正式生产。
