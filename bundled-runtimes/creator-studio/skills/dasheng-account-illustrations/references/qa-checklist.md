# QA Checklist（账号绑定插图验收）

生成后逐项检查，任一不达标即重生成：

## 通用
- [ ] 单图单概念/单组对话（不贪多）
- [ ] 无事实数据出现在插图中（数字/图表留给数据图）
- [ ] 无 logo/水印/二维码/随机乱码文字
- [ ] 中文标注无错别字
- [ ] 与所在文章段落语义强相关（不是装饰贴纸）

## 默丘利Lab（胖版奥林匹斯固定角色组）
- [ ] 角色与段落机制匹配：信息=墨丘利、主权=宙斯、策略=雅典娜、流动性=波塞冬、信用=哈迪斯、资本开支=赫菲斯托斯、增长=阿波罗、竞争=阿瑞斯
- [ ] 全部角色是大圆头、圆滚短身、短手短腿的胖版造型，可爱但不幼稚
- [ ] 每个角色的标志物清晰，不能画成无法识别的通用萌系小人
- [ ] 同一角色跨图的体型、配色、脸部比例和标志物一致
- [ ] 线条精美（陶罐画韵律），无粗糙感——粗糙对这个账号是缺陷
- [ ] 配色守纪：米白/墨黑/赭红/爱琴海蓝，无多余彩色
- [ ] 单图最多三角色，分镜节拍与段落节奏匹配

## Newma牛马进化论（牛人+马人）
- [ ] 双角色同框（对话/互动），不是单角色
- [ ] 足够粗糙：歪线、廉价配色、手写标注——**太精美 = 不合格**
- [ ] 只用于文章开篇，正文没有第二张牛马角色图
- [ ] 严格一问一答：牛人提问，马人一句话概括全文核心判断
- [ ] 对话短促、中文准确、移动端可读，没有第三句补充说明
- [ ] 牛人=土黄大红、马人=荧光绿黑，颜色分工不混

## 墨丘利实验室（原版小黑）
- [ ] 纯黑简笔小人（无黄色、无叶子——与柠檬人严格区分）
- [ ] 实验室语境（仪器/流程/记录类动作）
- [ ] 深红单强调色克制使用
- [ ] 科研图表风的严谨感（衬线标注/中英混排）

## 记录
