# 基金研究模块边界

## 模块定位

当前项目只承担基金研究域中的三类核心工作：基金筛选、基金分析、基金经理评价。它输出可复核的研究证据、评分、对比结论和研究备忘录，不承接上游数据生产之外的资产配置流程，也不承接下游交易或治理流程。

## 范围内

- 全市场基金浏览、筛选、排序、候选池维护
- 单只基金研究：基础信息、业绩风险、滚动指标、同类分位、研究画像
- 基金经理评价：任职表现、风格稳定性、管理能力、历史报告
- 同类对比与矩阵：基金之间的业绩、风险、风格和证据对照
- 高级基金研究：因子镜头、主动收益归因、风险来源解释
- 研究备忘录：基于基金、经理、调研报告和指标证据生成可追溯研究文本

## 范围外

- 投委会、治理流程、会议纪要、审批流
- 组合构建、组合优化、组合模拟、资产配置
- 交易执行、订单管理、投后归因、客户适当性
- 面向最终买卖动作的自动决策或推荐

## 集成原则

- 下游系统只能消费本模块的研究输出，例如评分、研究备忘录、因子暴露、归因结果和对比矩阵。
- 本模块不保存下游决策结论，不承担审批状态，不生成组合权重。
- 新功能若无法归入基金筛选、基金分析或基金经理评价，应放到独立模块，而不是塞回本项目。
