# ADR-0004: 定位演进——从选基工具到专业基金研究工作台

日期：2026-08-19
状态：已接受

## 背景

项目四代演进中定位发生过一次关键转变：一代是"Wind 数据选基工具"（筛选 + 打分 + 推荐就绪），三代引入证据驱动与同类评价，四代建立研究工作流闭环（队列→论点→监控→异动→复盘）。V3.0 合并重构后，组合构建（M4）与基础回测/监控/交易清单（M5）相继落地，系统事实上已从"帮用户选基金的工具"演进为"专业基金研究员的研究工作台"。

这一演进使原有边界条款出现张力：旧边界禁止一切"组合"相关能力，但研究型组合构建（同类目标配置→等权/自定义权重→穿透分析→回测解释→再平衡提示→申赎清单研究输出）并不触碰投资决策与适当性边界。

## 决策

系统定位正式表述为：**面向专业基金研究员/基金经理个人的研究工作台**。边界按以下原则划分：

### 允许（研究能力）

1. **研究型组合构建**：目标配置（同类组维度）→ 推荐就绪准入 → 等权/自定义权重（单只 ≤40%）→ 持仓穿透（重仓股重叠/风格暴露聚合/净值相关性）
2. **基础回测**：以当前权重回看历史净值合成组合曲线，输出累计收益/年化/最大回撤/波动，并与分类映射基准对比。仅作解释，样本不足明确拒答
3. **组合监控**：目标配置偏离（阈值 5%）、成分风格漂移信号、再平衡研究提示
4. **交易清单生成**：目标组合 vs 当前持仓差异 → 申赎建议清单（方向/权重变化/金额/份额参考）。属研究输出，页面与 API 均明示"仅供专业用户自行决策"

### 禁止（越界能力，scope smoke 持续守卫）

1. **组合优化/模拟/决策**：均值方差优化、风险平价（属资产配置工具，明确不越界）、Black-Litterman、组合决策自动化
2. **投资决策与适当性**：面向非专业投资者的推荐、适当性判断、销售规则生成
3. **归因越位**：Barra/Brinson 归因只用于解释，不进入评分与排序

## 理由

- 用户（权益基金经理）为专业投资者，交易清单是研究流程的自然终点：研究→构建→监控→调仓分析。止步于"清单"而不执行，既满足研究闭环，又不触碰决策与交易执行
- 风险平价等资产配置技术被明确排除，因为它们是"资产配置"领域工具，超出"基金研究"边界（用户在 M5 方案确认时原话："风险平价是资产配置的东西，不需要越界"）
- 回测只做基础版（合成曲线+指标+基准对比），不做归因、不做参数优化重跑，防止回测被误用为选基依据

## 后果

- `fund_research_scope_smoke` 禁令语义已同步演进：移除对 `api/portfolio` 的全局禁止，保留"组合优化/组合模拟/组合决策/投资决策"禁令
- 交易清单 API 与页面必须携带边界声明；清单不落库（研究输出，时点性结论）
- 后续如引入更深的组合能力（如再平衡执行、定投计划），需先修订本 ADR 并重新评估合规边界
