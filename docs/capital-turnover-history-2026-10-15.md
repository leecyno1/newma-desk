# 成交基线与集中度研究 · 2026-10-15

## 本轮范围

在资金总览的成交活跃度内增加“研究20/60日成交基线”。沿用 Tushare daily、交易日历及 CapitalHistoryStore，无新增依赖，不影响总览默认首屏请求。

按 finance-data-router 核对 [Tushare 日线字段](https://tushare.pro/document/2?doc_id=27)：amount 为千元，展示转人民币亿元。按照 search-first 的快速流程复用已有分页和缓存；本轮没有引入外部分析模型。

## 统计定义

- 20/60日基线分别需要最新日加此前20/60个交易日，均值不包含最新日。
- 比较池为整个窗口内每日都有有效行情的股票交集，避免新股、停牌、缺数改变分母。
- 成交倍数 = 共同样本最新成交额 / 此前N日同一共同样本平均成交额。
- 历史分位 = 此前N日成交额不高于最新值的天数 / N，不是预测概率。
- 每日在共同样本内重排成交前20名；集中度变化 = 最新占比减此前N日占比均值，单位为百分点。
- 显示共同股票数、最新日返回股票数、排除数，以及共同样本最新成交额。它与上方单日全样本不是同一统计池。
- 任一交易日缺失、分页异常、金额冲突或日历未确认，不计算可确认基线。共同样本少于20只也不确认。

共同样本法仍存在选择偏差，不代表全市场；20与60日交集不同，不能直接将两组金额相减。

## 运行与交互

接口：`GET /api/capital-flow/turnover-history?days=20|60&refresh=true|false`。

每次最多补齐8个交易日，最多3日并发；页面展示进度并继续有边界的补齐请求，遇到失败停止并提供重试。既有历史按日复用，最新日5分钟后重取；刷新只重取最新日和缺口，不追溯历史修订。

切换窗口取消旧页面请求，旧窗口的结果不会被发布到新窗口。收起后停止继续补齐。失败保留快照但撤销确认。Agent 获得当前展开状态、窗口、进度、比较池、逐日序列、失败和确认标识。

## 真实样本核验

截止2026-10-14，单日返回5,563只。

| 指标 | 20日基线 | 60日基线 |
| --- | ---: | ---: |
| 行情日覆盖（含最新日） | 21/21 | 61/61 |
| 固定共同股票数 | 5,521 | 5,441 |
| 排除最新日样本数 | 42 | 122 |
| 共同样本最新成交额/亿元 | 14,074.80 | 13,878.40 |
| 历史均值/亿元 | 17,635.38 | 20,656.01 |
| 成交倍数 | 0.7981 | 0.6719 |
| 历史分位 | 5.00% | 1.67% |
| 前20集中度较均值/百分点 | -1.65 | -2.98 |

这只说明该共同样本成交低于历史均值、集中度低于历史均值，不推断外部资金净流出或未来市场方向。
