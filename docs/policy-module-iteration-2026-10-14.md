# 政策模块深化 · 2026-10-14

范围仅为政策日历、政策流、政策解读、政策渠道。四入口更新为 0.5.0，本地编译及注册，不部署、不自动推送 Git；其他项目的既有改动保留。

## 本轮改进

### 政策日历

- 从多年月份整页展开改为默认当前月份，可前后切月、选择月份、返回本月，切换月历与议程。
- 同一政策分别保留发布节点和明确施行节点。施行节点要求已读取正文且有施行条款引文；没有依据不猜日期。
- 官方日程、按惯例生成的预期窗口分开。LPR 月度锚点没有假装已做法定节假日校准，PMI 月末锚点也不冒充官方预约。
- LPR、PMI 观察窗口按当前月滚动四个月，可跨年；货币政策执行报告显示季度观察锚点。
- 未来日期摘要纳入正文确认的施行日，不覆盖政策发布日期。
- 空月份不选择其他月份的政策；Agent 获得相同月份、日期口径、可见节点和选中节点类型。

### 政策流

- 默认近 90 天，支持近 30 天与全部历史；按发布机构、文档类型、生命周期、量级、关键词和是否已有正文筛选。
- 明确标示正文可读版本或待读取，不将发现标题视作已经读过政策。
- 日期降序研究清单，筛选后当前对象与 Agent 可见列表一致。
- 官方链接导入与关联文件跳转会清除阻挡目标政策的筛选条件。

### 政策解读

- 沿用官方正文、条款差异、传导假设、指标与失效条件研究链路，新增研究跟踪。
- 保存底稿快照、持仓关联结论、实际观察/反证、复核日期和工作状态。跟踪状态不是投资假设验证结论，不自动下单或生成组合告警。
- 使用 SDK 的 Desk-managed storage，隔离用户与工作区；不另外搭建 Agent 内核或研究数据库。命名空间仅归政策解读，不宣称四个 Mod 共享同一私有跟踪表。
- 保存正文依据版本；重新打开可恢复底稿。当前正文与旧底稿版本不一致时页面和 Agent 上下文均提示，不悄悄迁移研究结论。
- 写入使用存储版本检查；冲突保留草稿、不自动覆盖。读取失败不允许当作空记录覆盖。
- 独立裸页没有 Desk 会话时明确说明持久跟踪不可用，正文、底稿和导出仍可用。AI 保留配置的 Newma、本地 CLI、Copilot 路径，本轮未评价模型回答质量。

### 政策渠道

- 来源身份与研究范围、正文可读/本地已载入、最近成功、最近尝试、异常原因及官方入口直接展示。
- 支持只看异常/未配置渠道。失败原因可展开，小屏幕保留健康状态。
- 正文覆盖按官方主机归属统计，仅代表本地记录，不代表官方文库的全量覆盖。

### 共同设计与判断口径

- 深蓝研究台、青绿证据线、琥珀时间节点；嵌入页移除独立刷新大行，刷新并入采集状态栏。保留 Desk 标题与二级导航，不增加重复标题。
- 预设量级统一为未人工确认的规则初筛。真正人工复核以复核记录为准，采集重跑不覆盖。
- 截至本轮，未新增二级菜单。跟踪先在解读页形成可保存的研究闭环，待跨政策复核清单、责任人与提醒机制成熟后，再评估独立“政策跟踪”。不重复全球模块的贸易/制裁研究，也不在此重做组合风控。

## 外部研究与采纳

- [OpenStates core](https://github.com/openstates/openstates-core)，MIT：借鉴正文版本、进程动作、关联文件与日程分离。本轮直接落实发布/施行节点分离，没有引入其服务。
- [changedetection.io](https://github.com/dgtlmoon/changedetection.io)，Apache-2.0：借鉴正文筛选和实质变化提示；沿用已有正文快照/对照，本轮补充旧底稿版本失配提示。README 中的托管 AI 功能不冒称开源组件。
- [PolicyEngine US](https://github.com/PolicyEngine/policyengine-us)，AGPL-3.0：吸收规则参数、日期版本、基准/情景可复现理念；它是美国税收福利模型，不适合作为中国政策或股票收益引擎直接搬入。
- [Federal Register API](https://www.federalregister.gov/developers/documentation/api/v1)：API 样本区分 publication_date、effective_on、comments_close_on、dates；文档网页本次受 CAPTCHA 阻挡，但 [2026-20902 JSON](https://www.federalregister.gov/api/v1/documents/2026-20902.json) 可读。借鉴日期语义，不声称已接入美国完整政策源。
- policy-monitor 技能影响证据口径：一手来源、日期分层、事实/假设/不确定性分开，未确认不升级为官方事实。

## 验收范围

模块构建、6 项前端核心规则测试、29 项政策后端测试及 1 项既有上下文回归通过。
8 项浏览器验收覆盖：真实“人工智能+”官方正文导入、生成底稿、导出、跟踪保存与重新打开；失败保留证据；独立页；四个 Desk 入口；月历与施行节点；政策流筛选/上下文一致；小屏渠道异常；研究保存冲突。

浏览器中的真实研究跟踪写入独立验收工作区，不修改实际持仓或交易。模型调用不在本轮底稿生成中自动触发。

## 仍待完善

1. 人民银行、商务部采集适配仍有 503；其他来源也可能波动。页面显示每次尝试与最近成功，不把界面升级当作数据源已修复。
2. PDF、附件、征求意见截止日的可靠正文识别；未确认的截止时间不生成日程。
3. 研究跟踪与统一档案的引用、跨政策复核清单、提醒及具体条款的人工关系确认。
4. 使用真实持仓做影响范围匹配；当前“持仓关联”是用户记录，并非自动识别结果。
5. 政策是否落地、指标是否验证仍需真实数据与人工判断，不能靠模板生成自动宣称有效。
