# 深市／北交所官方融资核验 · 2026-10-15

## 本轮交付

继续深化「资金 → 个股资金」，补齐深交所、北交所官方金额适配，不引入 AKShare、Pandas 或通用表格框架。沿用 Tushare 主源及既有资金历史、独立公开来源缓存和 Agent 上下文。

- 上交所：原始明细可提供四项金额，完整匹配才显示四项确认。
- 深交所：同日 JSON 报表确认日期、证券和网页口径，再读取官方 XLSX 的精确元金额。JSON 页面只有0.01亿元精度，部分数值截断，不能用于精确到元的金额比较。XLSX只解析所需表头和证券行，不依赖额外框架。
- 北交所：解析官方 JSONP，同时校验返回日期和证券行的 `sxrq`；使用 `rzye`、`rzmre` 原始元字段，不使用 `Round` 万元显示字段。接口实测忽略证券代码筛选，因此有界分页直到目标证券，最多16页，未完整查询不能报无记录。

深交所和北交所当前明细都未单列融资偿还额：核对前日余额、当日买入、当日余额，三项一致显示「已核对3/4项 · 偿还额未披露」。偿还额及官方完整勾稽差额保持空值，不从余额反推补齐，更不能把Tushare字段放回官方栏造成循环验证。金额一致不代表确认差额原因或整体风险。

## 普通日期也能核验

不再只对非零差额日执行官方核验。用户可以从最近20个可勾稽交易日选普通日期；默认优先最大差额日，无差额时选择最近完整两日样本。仍保留差异清单，核验不改变原始Tushare差额。

页面提供交易所名称、源站入口、核验日和前一日状态、四字段来源对照及披露缺口。所选日、官方原始字段、精确金额单位、日期证据、匹配计数与缺项同步给 Agent。切换股票撤销旧确认，来源失败保留历史并标失败，不将旧记录作为本次确认。

每个交易所日期查询最多12秒，缓存5分钟；没有后台无界抓取或跨日补值。若官方请求的日期回退到较早披露日，直接拒绝确认。2026-10-15实测深交所请求10-14报表曾返回10-13日期，已按该规则拒绝。
