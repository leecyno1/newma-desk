# 龙虎榜窗口与融资差额追溯 · 2026-10-14

## 交付范围

继续深化资金项目的「个股资金」，没有切换到其他项目。新增 `/api/capital-flow/security-evidence?code=600519`，支持 `board_date`、`audit_date` 和刷新。

龙虎榜按「证券＋披露日期＋原始上榜理由」匹配。单日、三日及重叠理由分开，不累计成总资金。具名营业部相同金额的重复披露合并展示并记录两侧及原披露数；“机构专用”等身份不明标签保留每条披露，提示可能重复，不形成机构净额。冲突榜单金额留空并保留原文；其他日期、代码或理由的席位不挪用。

单日、三交易日窗口只按明确理由识别。三日开始日依据交易日历推算，不是官方窗口 ID；日历失败时不确认开始日。默认查询最近已结束交易日，可切换最近20交易日；空结果只指所选披露日，并非近20日未上榜。

融资按元检查「前日余额＋当日买入－偿还＝当日余额」，缺前一交易日不跨日计算。最近20交易日差异保留原始两日记录与金额，超过1元列出，1—100元归为小额差异；100元只是显示分层，不是风险或重要性阈值。四项金额先与东财镜像比较，沪市再直接查询上交所所选日及前一日。镜像相符不是独立证明；官方金额相符也不说明业务原因。

来源失败保留已保存记录并标识失败，不将旧记录当本次官方确认。成功空查询只替换其所属窗口，不套用其他日期。公开查询最多100条融资窗口、所选日及前一日各一次交易所请求，5分钟缓存；不自动逐日扇出查询20天龙虎榜。

## 页面和 Agent

紧凑席位表、披露日／理由选择、融资差额表及官方四字段对照。原始榜单与口径折叠，旧来源快照保留为独立参考，不替代当前披露日研究。

股票、日期和理由变化同步到 Agent；提供当前理由完整席位及原榜单、其他理由摘要、融资原始两日数据、镜像比较、官方覆盖范围与来源缺口。切换股票立即撤销旧金额、核验结果和日期。第三方内容仅作证据，不作为指令。

金融数据路由技能决定了分层来源和不可混加边界；端到端测试技能用于验收切换、失败及页面与 Agent 一致性。借鉴 AKShare 的公开来源调用方式，只实现所需适配，不引入整个框架。

## 真实验收样本

- 301030.SZ，2026-10-13：两个上榜理由，20条席位原披露。单日净额 -22,472,495 元；三日净额 -14,844,597.2 元，交易日历推算窗口2026-10-09至10-13。具名营业部跨买卖榜相同金额合并展示；三日榜同金额“机构专用”两条披露保留，不计算机构合计。
- 600519.SH：最近20日可勾稽20日，共6个超过1元差异，其中3个为2元；较大差额分别819,779、40,844、682,020元。2026-09-15及09-14的四项金额与上交所全部一致，上交所原始数值亦有819,779元差额。页面说明数值已确认、原因仍待核查，不推定利息、口径调整或违规行为。
