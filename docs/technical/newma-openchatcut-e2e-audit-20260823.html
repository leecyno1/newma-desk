审批卡在 Runtime 重建后消失

审批请求已进入持久账本。新 Runtime 只恢复仍为 pending 的审批；allowed、denied 等历史决定绝不恢复为授权。

旧 Runtime 清理让新 Runtime 丢失执行权

运行所有权在重建时显式交接。旧实例退出不会再撤销新实例已接管的 Agent Run。

MCP 异常退出留下孤儿 Draft

孤儿清理会投递到当前工程编辑器；Broker 重启后，新连接只允许取消已无主的 Draft，不能接管或修改它。
