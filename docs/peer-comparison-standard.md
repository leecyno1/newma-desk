# Newma-Desk 同业比较标准

日期：2026-08-04
合同：`newma-desk.peer-comparison.v1`

## 目标

同业比较 Mod 负责把“看起来类似的公司”变成经过口径审计的可比公司集合，并用统一指标、统计分布和竞争证据解释差异。

```text
明确研究问题
    ↓
选择目标公司与候选同业
    ↓
审计业务模式 / 区域 / 客户 / 产品 / 财年 / 币种
    ↓
统一 5–10 个关键经营与估值指标
    ↓
最大 / 75 分位 / 中位 / 25 分位 / 最小
    ↓
解释竞争优势、结构性脆弱点和变化轨迹
    ↓
更新投资逻辑与后续跟踪清单
```

页面不直接输出“高估、低估”、评级、目标价、买卖或仓位建议。

## 可比公司规则

1. 业务模式、主要产品、客户、区域或价值链位置至少存在明确重叠。
2. 每家公司必须标记为目标公司、直接同业、相邻对手或新进入者。
3. 业务结构、财年、币种、会计定义、并购和一次性项目等差异进入 `exceptions`。
4. 缺少可比性的公司应排除；三家高质量同业优于六家勉强同业。
5. 同业集合必须且只能有一家目标公司。

## 指标与统计

首版复用 Equity Research Comparison 的标准化指标：

- 营收与净利润增长；
- 毛利率、净利率、ROE、现金转化与资产负债率；
- PE、PB 和估值历史分位；
- 质量、增长、估值和韧性评分。

默认控制在 5–10 个指标。页面自动计算最大值、75 分位、中位数、25 分位和最小值。绝对规模不做简单优劣排序；估值倍数必须结合增长、利润率、现金质量和业务差异解释。

缺失值显示为 `N/A`，不得用模型记忆或无来源估算静默填补。负利润、负 EBITDA 或明显不可比的分母不能机械套用倍数。

## 来源与期间

每家公司都关联自己的 Equity Research Evidence Ledger，保留：

- 报告期和生成时间；
- 数据来源与覆盖率；
- 指标单位、币种和定义；
- 信息缺口和失败状态。

报告期不一致时，合同将 `fiscalAlignment` 标记为 `mixed`，Agent 和页面必须显式提醒时间错位。

## 竞争分析

结构化竞争维度优先覆盖：

- 网络效应；
- 转换成本；
- 规模经济；
- 品牌、专利、许可、数据等无形资产；
- 行业特定指标，例如 ARR、订单、产能利用率、库存周转或同店增长。

每个维度区分当前状态和变化轨迹，并同时记录难以复制的优势与难以修复的脆弱点。

## 存储与运行边界

Mod 不新增数据库、服务、端口或 Agent，复用：

- `equityResearchComparison`：跨市场标准化指标和评分；
- `equityResearch`：Evidence Ledger、报告期、来源和缺口；
- Desk-managed Storage：保存同业集合、可比性判断和竞争结论；
- Desk Agent：继续补充行业特定指标、市场份额和战略证据。

存储配置：

- namespace：`peer-comparison`
- document key：`cases`
- scope：`user-workspace`
- schema version：`1`
- local fallback：`newma-desk.peer-comparison.v1`

## 接入要求

其他项目复用本标准时应：

1. 使用共享合同或提供无损映射；
2. 保留稳定的 case、member、metric、source 和 strategic-dimension ID；
3. 显式记录纳入理由与口径例外；
4. 所有硬数据附来源、期间、单位和币种；
5. 将目标公司、同业集合和研究问题发布到 Agent Context；
6. 不在 Mod 内重复实现 Agent、模型配置、聊天记录或 Excel 生成器。

完整 Excel/PPT 同业分析属于可选 Agent 交付物，不进入 Mod 运行时代码。
