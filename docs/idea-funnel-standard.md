# Newma-Desk 研究机会池标准

Mod：`idea-funnel`
合同：`newma-desk.idea-funnel.v1`
存储：`idea-funnel/pipeline`
兼容级别：Level 3

## 1. 定位

研究机会池位于市场扫描、资讯、产业链、自选和深度研究之间，负责把零散线索转成可比较、可证伪、可交接的研究候选。

标准流程：

```text
市场扫描 / 主题 / 新闻 / 催化剂 / 产业链 / 自选
                         ↓
线索箱 → 初筛 → 短名单 → 深度研究 → 交接
                         ↓
投资逻辑 / 财报 / 同业 / 估值 / 研究备忘录
```

机会池不输出投资结论。任何量化筛选、主题线索或 Agent 发现都只是研究候选，必须经过基本面核验。

## 2. 候选最小结构

每个候选至少包含：

- 市场、证券代码、名称和币种；
- 线索来源、来源 Mod、档案 ID、截至日期和发现时间；
- 市场、行业、主题、市值范围与筛选规则；
- 一个明确的研究问题；
- 初始假设和同等强度的反方假设；
- 为什么是现在、市场可能遗漏什么；
- 至少两条支持、挑战或中性信号；
- 研究优先级评分；
- 至少一项风险、证伪条件和下一步任务；
- 交接目标和状态；
- 来源、数据缺口及阶段复盘。

## 3. 筛选方法

筛选规则必须记录：

```text
metric + operator + value + rationale
```

支持的研究风格：价值、成长、质量、事件驱动、特殊情形、风险线索和其他。

常见筛选可以参考增长、估值、盈利质量、现金流、资产负债、事件和风险指标，但不得把通用阈值固化成所有市场、行业和周期均适用的结论。每个规则必须说明为什么与当前研究问题相关。

## 4. 双向假设

机会池固定保留：

- `initialHypothesis`：候选值得继续研究的最强解释；
- `opposingHypothesis`：能够推翻或显著削弱初始假设的合理解释。

页面必须同时保存支持和挑战信号。只有支持证据、没有反方证据的候选不能视为完成初筛。

## 5. 研究优先级

评分维度均为 0–100：

- 研究相关性；
- 证据质量；
- 认知新颖度；
- 催化清晰度；
- 可证伪性；
- 研究成本。

总分计算：

```text
(相关性 + 证据质量 + 新颖度 + 催化清晰度 + 可证伪性 + 100 - 研究成本) / 6
```

该分数只用于确定研究顺序，不代表预期收益、目标价、评级或交易动作。

## 6. 阶段与交接

标准阶段：

- `inbox`：尚未审计的原始线索；
- `triage`：正在核验身份、来源和筛选条件；
- `shortlist`：双向假设、风险和下一步任务已完整；
- `deep-dive`：已经进入一个或多个深度研究 Mod；
- `handoff`：已形成结构化研究档案；
- `deferred`：当前缺少催化剂、证据或研究资源；
- `closed`：线索被证伪、重复或不再相关。

交接目标使用稳定 Mod ID：

- `thesis-tracker`；
- `earnings-workbench`；
- `peer-comparison`；
- `valuation-workbench`；
- `research-memo`。

首版只保存交接目标、任务和来源档案 ID，不复制目标 Mod 的底层数据，也不自动伪造新档案。

## 7. 流程总览

机会池同时提供“候选与任务”和“流程总览”两个视图。流程总览不建立新的存储合同，而是从当前 Desk 工作区缓存实时派生以下轻量状态：

- 机会池阶段与未完成研究任务；
- 投资逻辑和研究备忘录的下次复核日期；
- 财报、同业、估值等档案的最近更新时间；
- 来源数量、陈旧或不可用来源、数据缺口和未通过审计项；
- 尚未覆盖的研究环节与下一研究入口。

流程总览只保存引用关系和派生状态，不复制六个来源 Mod 的底层档案。排序优先级为复核到期、任务逾期、来源陈旧和覆盖缺口；“下一研究入口”只表示工作流衔接，不表示投资优先级。

## 8. Agent Context

右侧 Desk Agent 可以读取当前候选的筛选方法、正反假设、信号、评分、风险、催化剂、任务、来源、缺口与交接状态。

默认问题组：

- 筛选与排序：审计入池依据、比较候选优先级；
- 流程审计：定位复核到期、任务逾期、来源陈旧和档案缺口；
- 双向假设：强化正反路径、主动搜索冲突证据；
- 补证与交接：读取页面之外的数据、形成深度研究任务包和滚动复核清单。

Agent 可以补充长周期财务、行情、公告、同业、估值、产业链、新闻、所有权与拥挤度信息，但必须注明来源、截至日期以及它如何改变候选优先级。

## 9. 存储与依赖

- Desk-managed Storage 命名空间：`idea-funnel`；
- 文档键：`pipeline`；
- 本地缓存：`newma-desk.idea-funnel.v1`；
- 流程总览只读取各研究 Mod 的既有缓存，不新增数据库、存储命名空间或跨 Mod 数据副本；
- 支持 `security.selected`；
- 可从 Research 同源自选缓存创建候选；
- 不新增数据库、端口、服务、模型设置或独立 Agent；
- 页面懒加载，单页构建产物保持低于 256 KiB。
