本地基础仓库位于 `bundled-runtimes/rsshub-policy`，固定 revision
ddaa58f793eb5c5a8075ec507ce86dcd2e17cd95。公共 RSSHub 实例在当前网络中超时，
因此产品运行时不依赖公共实例；后续自建采集器可按接口返回的 rssHubPath 接入。

动态采集通过环境变量 NEWMA_DESK_POLICY_RSSHUB_BASE_URL 启用，例如指向本机
http://127.0.0.1:1200。未配置或采集失败时，页面继续展示核验过的历史政策和未来
日程，并在 API 的 collector.status 中明确标注 not-configured、degraded 或
unavailable，不会用二手媒体数据冒充官方原文。

Desk 统一启动器会在依赖和路由索引就绪时启动本地 RSSHub。2026-08-15 实测证监会、
发改委、金融监管总局路由可用；中国政府网、人民银行、财政部、工信部、商务部路由
因官网结构变化降级。渠道状态按每次请求实时返回，不把失效路由标成正常。

## 官方渠道

- 中国政府网：国务院政策、重要会议、政策文件和解读。
- 中国人民银行：货币政策执行报告、LPR、公开市场和金融统计。
- 中国证监会：资本市场制度、监管规则、发布会和处罚。
- 国家发展改革委：宏观调控、产业、价格、投资和区域政策。
- 财政部：预算、税收、专项债、政府债务和财政执行。
- 国家金融监督管理总局：银行保险监管和行政处罚。
- 工业和信息化部：工业、通信、数字经济与产业政策。
- 商务部：外贸、外资、消费和国际经贸。
- 国家统计局：GDP、CPI、PPI、PMI 等政策验证数据。

所有研究记录必须保留官方原文 URL。采集源只负责发现，不作为最终证据。

## 三级量级

- L3 战略级：改变宏观政策框架、制度规则或全市场定价。
- L2 行业级：显著影响一个或多个行业、资产或资金成本。
- L1 执行级：局部规则、例行数据或执行口径调整。

评分依据同时展示，不输出无法解释的单一分数。未来日期区分：

- official：官方已公布日期。
- calendar-rule：固定统计或政策日历，遇节假日可能顺延。
- expected-window：基于历史规律的观察窗口，不等同于官方预约。

## MVP 架构

1. policy_analysis API 提供统一事件、官方渠道、量级与日期可信类型，并从自建 RSSHub 增量合并官方动态。
2. policy-analysis 前端 Mod 提供日历、政策流、渠道和详情研究视图。
3. RSSHub 保持独立 Git 与 AGPL 边界，作为可替换采集层。
4. Mod 使用 Newma Bridge 发布上下文、响应刷新动作并跟随 Desk 主题。
