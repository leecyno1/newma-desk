# 多日期信号追踪 · 0.4.7

入口：资金总览 → 启用异常成交研究 → 多日期追踪。日期按钮可打开相应候选、整组统计和非候选对照。

## 本轮实现

- 复用同一批26日行情、已有冻结快照、筛选与同期对照函数，展示最近6个信号日；无逐只新请求、无新依赖。历史日期不会被追踪功能补写为首次记录。
- 分开显示已保存、事后重算、首次保存北京时间、候选数和后1/3/5日中位差。分页不改变追踪范围，切日/失败状态同步Agent。
- 入场前记录：首次保存时间须处于信号日15:00收盘后至下一交易日09:30开盘前（北京时间）；开盘时刻本身归为晚记录。下一交易日尚未进入取得的日历则待确认，不按周一至周五猜节假日。
- 无时区、缺失或早于信号收盘的时间不通过时点核验。时间核验不证明底层数据在当时已可得，也不证明能够成交。
- 「完整可比较期数」只计时点合格且两组样本非空、行情完整的日期。未到期、行情缺失、旧快照缺对照范围、晚记录及事后重算均不计入。
- 只展示最近6个日期，不声称已支持长期统计；重复股票与重叠窗口不作为独立样本，不生成合并胜率或策略有效性判断。
- 记录发生于访问研究页面时，不是后台自动采集；未新增定时任务。
- 统计、对照和追踪组件改为按需加载，主包498.60kB（gzip143.82kB），消除此前500kB提示。
- 使用 search-first 复用现有计算和标准时间库；金融数据路由与e2e-testing分别约束时间口径和页面验收。本轮没有外部模型或全网项目检索。
