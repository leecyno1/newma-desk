# 市场情绪：第一项口径与上下文整改

## 本轮范围

完成统计口径、缺数和刷新状态整改；不把本轮视为历史趋势或连板研究完成。

- 上涨参与率使用上涨 /（上涨 + 下跌 + 平盘），不再排除平盘。
- 取消 70/30 混合情绪分数；缺失不补零、不补中性。
- 涨停 /（涨停 + 跌停）单独呈现，明确不等于封板率或胜率。
- 保留明确的真实零；无分母、无效计数和矛盾计数不生成比例。
- 来源统计日与接口获取时间分开；未核验交易日历和盘中时点，不标为实时。
- 刷新开始、失败均撤下旧统计，并同步撤下 Agent 旧证据。
- 市场范围固定为 A 股，不再随个股报价或证券切换事件变化，不请求个股报价。
- 行业前12项标为截面而非全行业扩散率；只有确认大单净额口径才展示亿元值。
- 修复移除报价栏后的桌面网格行高，以及窄屏底栏覆盖、页面横向溢出。

## 第二轮：真实日终统计接通

上面的接口失败记录为第一轮状态。本轮新增明确的 `market.sentiment` 能力，由 `market-breadth-data` 提供；不再让情绪页等待乐咕和东方财富行业接口。

- `/api/capital-flow/sentiment` 仅转换 `TurnoverResearchService` 的既有日线样本，复用交易日历、分页和历史库，不增加第二份采集或数据库。
- Desk 嵌入走已声明的 Mod action；无宿主时通过统一数据网关调用同一能力，浏览器不接触 Tushare 密钥。
- 上涨占比、涨跌幅中位数、七档涨跌分布、有效样本及排除项同步进入页面与 Agent 上下文。
- 仅覆盖来源返回且成交额、价格和涨跌幅有效的沪深北 A 股样本；不宣称交易所全集。
- 固定昨日及以前最近交易日，交易日历确认后可标为日终 `fresh`，永不标盘中 `live`；日期不匹配或保留旧快照不得冒充更新成功。
- 刷新失败撤下计数与分布；不将旧样本或缺数变成零。
- 不使用涨幅阈值推断涨跌停，不把不同日期的乐咕计数拼入日线样本。行业资金继续由资金模块负责。

## 第三轮：20交易日固定样本趋势

- 新增 `market.sentiment-history`，嵌入和独立模式统一通过数据能力调用。
- 扩展既有 `capital.turnover-history.v1`，在原成交额记录中同时保存有效价格对应的涨跌幅；旧的仅成交额记录按需补齐，不另建历史库。
- 每批最多8个交易日、并发3个；单日分页总等待最多20秒。用户主动补齐下一批，不做无限轮询。
- 使用交易日历的最近20个已结束交易日（含最新日），固定窗口内共同有效样本。涨幅缺失、零成交、无效价格不当作平盘。
- 提供固定池上涨占比曲线、近5日与此前5日均值、百分点变化、上涨家数过半天数。曲线分母与上方单日样本不同，界面明确解释。
- 逐日表展示日期、可用状态、当日有效样本、共同池外排除数及统计；缺历史、日历未确认或共同池不足20只时不生成曲线或趋势均值。
- 刷新开始或失败撤下历史与Agent旧证据；日终单日统计独立加载，历史失败不会使单日统计失效。
- 固定池会排除新股、停牌和缺数股票，有选择偏差；窗口滚动也会改变池，不把该曲线宣称为全市场无偏回测。
