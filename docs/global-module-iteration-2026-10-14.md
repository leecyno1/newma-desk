# 全球栏目：二级模组深化与第一轮验收

## 定位与边界

按当前 `/api/mods` 注册结果，本栏目有六个二级页。全球栏目负责外部事件、地理关联与证据组织；宏观估值、公司研究、基金穿透和组合风控仍由对应模组承担。报道数量、上游规则分数、地理邻近和手动情景权重，不应包装成组合风险或买卖建议。

## 逐项深化顺序

| 二级页 | 本次检查结果 | 下一步核心深化 | 验收重点 |
| --- | --- | --- | --- |
| 全球情报 | 第一轮核心代码及 UI 改造完成。原 CARTO 瓦片显示 API Key 水印；原事件标题仅 10px，图层常驻挤占地图 | 地图与事件双向聚焦、可恢复工作区；事件/通道研究结果进入统一研究库 | 地图不依赖外部瓦片；图层与专注模式可切换；选中事件、点位、通道和 Agent 一致；不把施工公告当成中断 |
| 新闻与舆情 | 保留现有标题兜底、分页、筛选和原始报道链路；本次跑现有浏览器回归，不代表已深化全部业务 | 跨语言同事件去重与来源分歧；关注对象相关性；报道修订/辟谣追踪 | 不显示分类代替标题；热度与事件风险分开；事件簇可回溯到原始报道 |

| 中美贸易 | 实际接口有 BIS 近365天检索命中、纽约联储 GSCPI；出口限制强度与中方覆盖仍明确缺失 | 条款/生效日期/受限实体/产品编码/豁免的结构化证据，连接已有政策原文模块 | 检索命中数不是制裁强度；公布与生效分开；不把全球供应链压力当中美双边指标 |

每次开始上述下一项前，先说明具体范围、数据条件与交互取舍，再实现和验收；不同时堆砌多个空页面。

## 是否新增二级页

暂不新增。最值得提取的是“关键通道与供给”：海峡、港口、管线与能源运输；但全球情报已有通道，美伊专题已有海事证据。先形成共享通道组件，补可靠的通行量/运价/供给数据后再独立提取。

“制裁与出口管制”可先作为中美贸易的深度视图，待 OFAC/BIS/中方原文和实体匹配完整后再讨论独立二级页。灾害、航空、网络安全继续做图层，避免导航膨胀。

## 已落实的第一轮

- 继续使用 MapLibre GL 6.2 + deck.gl 9.3.9，没有增加另一套地图引擎。
- 地图优先布局、可展开图层、专注地图模式；深色海蓝/青绿、琥珀预警；事件标题13px、摘要12px。
- Natural Earth 1:110m 轮廓随源码打包，移除带 Key 水印的外部瓦片和远程国界请求。底图免联网不代表新闻/行情免联网；低分辨率轮廓不能用于导航或改变原始点位/通道距离计算。
- ResizeObserver 保持图层展开和窗口变化后的地图尺寸一致；国家风险变为0时清除旧着色。
- 投资传导复用已有通道匹配、暴露类别与市场观测；分开证据可用性、研究假设、验证指标、撤销条件及数据缺口，不伪造持仓映射。
- 修复光缆施工公告被上游分数包装成“疑似中断”；保留上游分数作来源字段，故障状态明确未核验，模型生成时间不当事件发生时间。
- Agent 上下文包含当前选中的事件/点位/通道、实际可见面板和同一份传导研究；静态通道不沿用其他新闻的新鲜度。

## 参考与采纳

- [WorldMonitor](https://github.com/koala73/worldmonitor)：地图主舞台、多域信号、来源时效。吸收设计，不复制 AGPL 应用源码到 Apache 主仓。
- [RADAR](https://github.com/Syntax-Error-1337/radar)：紧凑状态和暗色情报界面；不采用干扰阅读的 CRT 特效。
- [kepler.gl](https://github.com/keplergl/kepler.gl)：图层面板与时间过滤；不安装整套额外工作台。
- [deck.gl 9.3.9 MapLibre 文档](https://github.com/visgl/deck.gl/blob/v9.3.9/docs/developer-guide/base-maps/using-with-maplibre.md)：保留当前 MapboxOverlay；不按 master 文档贸然换适配器。
- [GDELT DOC](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/) / [GEO](https://blog.gdeltproject.org/gdelt-geo-2-0-api-debuts/)：借鉴新闻时间线和来源对比。提及地点不是事件坐标；报道热度不是投资风险。
- [Natural Earth 公共领域条款](https://www.naturalearthdata.com/about/terms-of-use/)：本地打包的基础地理轮廓。
